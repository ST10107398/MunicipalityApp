# Municipality Citizen Services Application

A modern Windows Forms desktop application built in C# that enables citizens to 
engage with municipal services — report issues, browse local events and 
announcements, and track service requests.

# Overview 

The Municipality Citizen Services Application is a user friendly desktop application designed to strengthen thee connection between residents and their local municipality. It provides a modern, intuitive interface for citizens to:

- Report community issues with photo/document attachments
- Discover upcoming local events and announcements
- Recieve personalized event reccomendations

The application follows a clean, card-based design philosophy with a professional blue scheme, ensuring accessibility across a diverse user base.
